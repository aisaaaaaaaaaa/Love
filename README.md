# Secret Date Mission — Ultimate V3

Это уже не просто сайт с кнопками. Это интерактивный мини-квест для приглашения на свидание.

## Новые фишки V3

- локальный CSS-котик вместо внешних GIF
- персонализация по имени
- кнопка “Нет”, которую практически невозможно нажать
- миссия/прогресс
- анимации, сердечки, конфетти
- выбор даты, времени и настроения вечера
- настоящая рулетка ресторана на canvas
- скретч-карта с бонусом
- подпись “договора свидания” на canvas
- финальный билет
- таймер до свидания
- копирование плана
- экспорт в календарь `.ics`
- кнопка поделиться
- сохранение прогресса в localStorage
- без внешних библиотек

## Как запустить

Открой `index.html` в браузере.

## Как залить на хостинг

Загрузи содержимое папки `date_invite_ultimate_v3` в корень сайта:

- `index.html`
- `style.css`
- `script.js`
- `assets/favicon.svg`

## Где поменять имя отправителя

Открой `script.js` и измени:

```js
const CONFIG = {
  senderName: "Айсултан",
  defaultName: "Красавица",
  calendarDurationHours: 2,
};
```

## Где поменять варианты рулетки

В `script.js` измени массив:

```js
const RESTAURANTS = [...]
```

## Где поменять бонусы

В `script.js` измени массив:

```js
const BONUS_LIST = [...]
```
